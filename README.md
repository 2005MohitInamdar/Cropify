# 🌾 Cropify

**Cropify** is a smart digital marketplace connecting farmers directly with buyers and dealers. It allows farmers to list crops with pricing, quantity, and other details while buyers can browse, filter, and connect easily. With real-time chat and a transparent system, Cropify ensures fair pricing, seamless transactions, and better marketing opportunities for both parties.

---

## 📱 Features

- 🚜 **Farmer Interface** – Post crop listings with pricing details  
- 🛒 **Dealer Interface** – Browse available listings and contact farmers  
- 💬 **In-app Chat** – Real-time communication between farmers and buyers  
- 🔎 **Clean UI** – Easy-to-use and accessible for everyone  
- 📦 **Built with Flutter** – Cross-platform support (Android/iOS)

---

## 🛠️ Tech Stack

- **Frontend:** Flutter  
- **Authentication:** 
  - Firebase Authentication  
  - Supabase Authentication  
- **Database:**  
  - Firebase Firestore  
  - Supabase Realtime Database  
- **Storage:** Supabase Storage  
- **Platform Support:** Android & iOS
